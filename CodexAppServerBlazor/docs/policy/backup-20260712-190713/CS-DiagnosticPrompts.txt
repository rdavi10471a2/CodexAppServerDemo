Coding Services diagnostic prompts

1. Effective session context check

Use this when you want the agent to report the effective Coding Services session context rather than the raw instruction stack.

Report only the effective Coding Services session context for the selected workspace. Do not list system, developer, or user instruction hierarchy. Use exactly these sections in this order: 1. Coding Services host/session policy 2. Selected workspace and workspace-local AGENTS.md policy 3. Coding Services indexed workspace metadata 4. Environment metadata only if relevant 5. Constraints currently blocking action.

2. Workflow evidence check

Use this when you want the agent to prove it is following the governed edit path for the current turn.

Report the current governed workflow state for the selected workspace. Include: active task, chosen files, fresh refresh evidence for each task file, edit session id, current review state, and any gating constraint preventing the next step.

Recommendation

- Prefer prompt 1 for configuration/regression checks.
- Prefer prompt 2 when validating governed workflow behavior.
